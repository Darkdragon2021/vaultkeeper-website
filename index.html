VaultKeeper

Una aplicación de escritorio para ayudar a configurar y administrar copias de seguridad de bases de datos, con almacenamiento local y una opción de transferencia a Google Drive.

Conocer la aplicación Política de privacidad

¿Qué es VaultKeeper?

VaultKeeper está diseñada para facilitar la configuración del respaldo de bases de datos compatibles y administrar dónde se guardan sus archivos de copia. Las funciones disponibles dependen de la versión instalada y de la configuración del usuario.

  • Configuración de conexiones a motores de bases de datos compatibles.
  • Almacenamiento de copias de seguridad en una carpeta local elegida por el usuario.
  • Integración opcional con Google Drive para transferir archivos seleccionados o generados por la aplicación.

Google Drive

Si el usuario conecta Google Drive, VaultKeeper solicita autorización mediante Google OAuth. La integración está configurada para usar el permiso drive.file, destinado a los archivos que la aplicación crea o a los que el usuario le da acceso. El usuario puede retirar el acceso desde la configuración de su cuenta de Google.
